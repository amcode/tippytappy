How it works

Tippy Tappy sits in your menu bar. On first launch macOS asks for Input Monitoring permission — that's how it knows you're typing. It never records keystrokes, and the code is open for you to check.

  1. Install. Open the download, drag Tippy Tappy to Applications, open it.
  2. Allow Input Monitoring when prompted. If the menu bar still shows a warning, relaunch the app.
  3. Type. Watch the icon change while your mic is muted, and change back when you stop.
